# ByteWa releases

Installers and automatic updates for **ByteWa**, the free WhatsApp connector for Bytive CRM. This repository contains release files only; the source code is private.

## Download (always the latest version)

| Computer | Download |
|---|---|
| Windows 10/11 | [ByteWa-Setup.exe](https://github.com/himanshu-bytive/bytewa-releases/releases/latest/download/ByteWa-Setup.exe) |
| Mac with Apple Silicon (M1/M2/M3/M4) | [ByteWa-arm64.dmg](https://github.com/himanshu-bytive/bytewa-releases/releases/latest/download/ByteWa-arm64.dmg) |
| Mac with Intel | [ByteWa-x64.dmg](https://github.com/himanshu-bytive/bytewa-releases/releases/latest/download/ByteWa-x64.dmg) |

- **Windows:** if you see "Windows protected your PC", click **More info → Run anyway**.
- **Mac:** the first time, right-click the app and choose **Open**.

## Updates

- **Windows:** ByteWa updates itself automatically in the background and restarts for a few seconds. Your WhatsApp login is kept.
- **Mac:** ByteWa shows **Download ByteWa x.y.z** when a new version is out. Download it and replace the app.
